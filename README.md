# Zenvia Media

Strona firmowa Zenvia Media z portfolio projektów koncepcyjnych, interaktywnym kalkulatorem orientacyjnej ceny i formularzem kontaktowym.

## Uruchomienie

1. `npm install`
2. Skopiuj `.env.example` do `.env`
3. Uzupełnij `RESEND_API_KEY` i `CONTACT_EMAIL`
4. `npm start`
5. Otwórz `http://localhost:3000`

Pliku `.env` nie dodawaj do repozytorium.
